# Call of Bengal — UI 수정본

한국어·벵골어를 함께 제공하는 정적 민담 아카이브.

## 주요 파일
- `index.html` — 홈페이지, 검색 제출 버튼, 빈 목록/오류 구분
- `archive.html` — 장르·검색 필터 및 URL 상태 보존
- `sources.html` — 검증된 자료 소장처 및 판본 링크
- `about.html` — 소개
- `assets/style.css` — 반응형 및 글꼴 가독성
- `assets/site.js` — 데이터 로딩·필터 로직
- `data/stories.json` — 현재 빈 배열 (정식 기록을 확인 후 공개)

## 배포
압축을 풀어 모든 파일을 GitHub 저장소 루트에 폴더 구조 그대로 올리세요. ZIP 파일 자체를 올리지 않습니다.

## 참고
- 원전 서고의 2·3번 링크는 같은 이름의 **다른 편찬자가 만든 판본**으로, 원저자 초판이 아닙니다.
- 현재 외부 웹폰트 다운로드 없이 운영되므로 운영체제에 따라 벵골어 서체 모양이 달라질 수 있습니다.
- 모바일 실제 브라우저 검증은 별도로 필요합니다.
