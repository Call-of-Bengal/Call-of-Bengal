# Call of Bengal v4

GitHub Pages용 정적 사이트. v3의 모든 페이지를 포함하며 **원전 서고**를 추가했습니다.

- `index.html` — 홈페이지
- `archive.html` — 민담 자료실
- `sources.html` — 원전 서고 (신규)
- `stories/story-001.html` — 민담 상세 페이지 예시

## 배포
압축을 풀고 위 파일과 `stories` 폴더를 **저장소 최상위에 같은 구조로** 업로드합니다. 기존 파일은 교체합니다. ZIP 파일 자체를 올리면 안 됩니다.

## 자료 주의
원전 서고의 3개 역사적 서명/저자/연도는 기본적인 서지 소개용이며, 실제 원문 링크 및 판본 검증은 아직 하지 않았습니다. 민담 카드는 디자인 예시입니다.
