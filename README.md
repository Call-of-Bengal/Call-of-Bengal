# Call of Bengal v3 — Archive
GitHub Pages에 올릴 수 있는 정적 웹사이트.

파일 구조:
- `index.html` — 홈페이지
- `archive.html` — 민담 자료실 (검색 + 카테고리 필터)
- `stories/story-001.html` — 민담 상세 기록 예시

## 배포
압축을 풀고 **폴더 구조 그대로** GitHub 저장소 최상위에 업로드하세요. `index.html`과 `archive.html`은 같은 위치여야 합니다.

## 사용
홈페이지 메뉴 `민담 자료실` → `archive.html`.
자료실에서 검색어 입력 또는 분류 버튼 클릭.
첫 번째 민담을 클릭하면 상세 기록 예시 페이지로 이동.

현재 모든 민담 카드/삽화는 디자인 예시이며 검증된 실제 사료가 아닙니다.
